## 核心通信协议

```
┌──────────────┐                              ┌──────────────┐
│   前端文件    │                              │   后端文件    │
└──────────────┘                              └──────────────┘

websocket-client.js  ◄─────WebSocket─────►  WebSocketServer.py
                          (实时推送)
                          ws://5001

camera.js/pendulum.js ◄────HTTP GET/POST───►  WebCore.py
                          (状态/控制)
                          http://5000

                                              SerialConnect.py
                                                    │
                                                    ▼
                                              单片机(CH340)
```

## 数据流向简图

```
【视觉数据】
摄像头 → PendulumCore.py → PendulumState.py → WebSocketServer.py → websocket-client.js → pendulum.js

【串口数据】  
单片机 → SerialConnect.py → Exporter.py → PendulumState.py → WebCore.py → pendulum.js

【控制指令】
pendulum.js → WebCore.py → PendulumAPP.py → SerialConnect.py → 单片机

【实时显示】
PendulumState.py → WebSocketServer.py → websocket-client.js → chart.js/pendulum.js
```
