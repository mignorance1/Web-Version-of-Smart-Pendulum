## 核心数据流和函数连接关系

### 1. 前端到后端的HTTP请求

#### 摄像头画面获取
```
前端: camera.js → startCameraFeed()
HTTP GET: http://127.0.0.1:5000/video_feed
后端: WebCore.py → video_feed() → 返回摄像头画面流
```

#### 单摆状态获取
```
前端: pendulum.js → fetchAndSyncFromCamera()
HTTP GET: http://127.0.0.1:5000/get_pendulum_state
后端: WebCore.py → get_pendulum_state() → 返回PendulumState.getState()
```

#### 摆长数据获取
```
前端: pendulum.js → fetchPendulumLength()
HTTP GET: http://127.0.0.1:5000/get_pendulum_length
后端: WebCore.py → get_pendulum_length() → 返回PendulumState.state["physical_length"]
```

#### 角度数据获取
```
前端: pendulum.js → fetchPendulumAngle()
HTTP GET: http://127.0.0.1:5000/get_pendulum_angle
后端: WebCore.py → get_pendulum_angle() → 返回PendulumState.state["camera_angle"]
```

#### 控制命令发送
```
前端: pendulum.js → window.sendKey()
HTTP POST: http://127.0.0.1:5000/pendulum_key
后端: WebCore.py → pendulum_key() → 转发到PendulumAPP._keyEventWeb()
```

#### 鼠标事件发送
```
前端: camera.js → _onClick() / _onContextMenu()
HTTP POST: http://127.0.0.1:5000/pendulum_mouse
后端: WebCore.py → pendulum_mouse() → 转发到PendulumAPP._checkWebMouse()
```

#### ROI校准
```
前端: camera.js → _onKeyDown() (Enter键)
HTTP POST: http://127.0.0.1:5000/pendulum_roi
后端: WebCore.py → pendulum_roi() → 转发到PendulumAPP._checkWebRoi()
```

### 2. WebSocket实时通信

#### WebSocket连接建立
```
前端: websocket-client.js → PendulumWebSocket.connect()
WebSocket: ws://127.0.0.1:5001
后端: WebSocketServer.py → websocket_handler()
```

#### 实时数据推送
```
后端: WebSocketServer.py → broadcast_loop() → send_pendulum_state()
前端: websocket-client.js → _handleMessage() → onPendulumState回调
前端: main.js → pendulumWebSocket.onPendulumState() → Pendulum.syncPendulumAnimation()
```

#### 历史数据推送
```
后端: WebSocketServer.py → send_angle_history() / send_position_history()
前端: websocket-client.js → onAngleHistory() / onPositionHistory()
前端: chart.js → ChartModule.updateAngleChart() / updateXYChart()
```

### 3. 后端内部数据流

#### 摄像头数据处理
```
PendulumAPP.py → _drawn() → Detector_HSV.getHsvMask() → Analyzer.getAngleAndLine()
→ PendulumState.update() → WebSocketServer.update_frame()
```

#### 串口数据处理
```
SerialConnect.py → 接收单片机数据 → Exporter.recordSerialRaw()
→ PendulumAPP._processSerialData() → PendulumState.update(physical_length)
```

#### 状态管理
```
PendulumState.py → 统一状态管理
- state["camera_angle"]: 摄像头识别角度
- state["physical_length"]: 串口获取的摆长
- state["ball_x/y"]: 小球位置
- state["pivot_x/y"]: 摆轴位置
```

### 4. 关键变量和接口

#### 前端关键变量
```javascript
// pendulum.js
this.cameraAngle: 摄像头角度数据
this.params.physicalLength: 摆长参数
this.params.angle: 当前角度
this.isPollingLength: 摆长轮询状态

// websocket-client.js
this.connected: WebSocket连接状态
this.callbacks: 回调函数集合

// chart.js
this.angleHistory: 角度历史数据
this.positionHistory: 位置历史数据
```

#### 后端关键变量
```python
# PendulumState.py
state: 全局状态字典
hsv_lower/upper: HSV颜色阈值

# WebSocketServer.py
CLIENTS: WebSocket客户端集合
angle_history: 角度历史缓存
position_history: 位置历史缓存

# PendulumAPP.py
self.ball_center: 小球中心位置
self.physicalLength: 物理摆长
self.fps: 帧率
```

### 5. 数据同步机制

#### 角度数据同步
```
摄像头 → Detector_HSV → Analyzer → PendulumState.camera_angle
→ WebSocket推送 → 前端pendulum.cameraAngle → 动画显示
```

#### 摆长数据同步
```
单片机 → SerialConnect → PendulumState.physical_length
→ HTTP轮询 → 前端pendulum.params.physicalLength → 动画显示
```

#### 实时状态同步
```
PendulumState → WebSocketServer → 前端WebSocket → 各模块更新
```

## 系统特点

1. **双通道数据获取**: HTTP轮询 + WebSocket实时推送
2. **多源数据融合**: 摄像头角度 + 串口摆长
3. **实时可视化**: Canvas动画 + Chart.js图表
4. **模块化设计**: 前后端分离，功能模块独立
5. **状态统一管理**: PendulumState作为数据中枢
