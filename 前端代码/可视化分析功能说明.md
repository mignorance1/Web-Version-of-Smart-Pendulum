# 可视化分析功能说明

## 概述

本系统已经实现了基于真实实验数据的可视化分析功能，不再使用现成的图片，而是根据实验数据动态生成图表。

## 主要功能

### 1. 周期与摆长关系分析
- **T vs L 散点图与曲线拟合**：显示周期T与摆长L的关系，包含理论曲线
- **T vs √L 散点图与线性拟合**：显示周期T与摆长平方根√L的线性关系

### 2. 重力加速度与摆长关系分析
- **g vs L 散点图与曲线拟合**：显示计算得到的重力加速度g与摆长L的关系
- 包含标准重力加速度参考线和理论曲线

### 3. 周期与摆角关系分析
- **小摆角下的周期变化**：显示1-10°摆角范围内的周期变化
- 验证单摆等时性原理

## 使用方法

### 在主界面中使用
1. 点击"生成可视化分析"按钮
2. 系统会自动分析实验数据并生成图表
3. 可以通过标签页切换不同的分析视图

### 测试功能
1. 打开 `test-visualization.html` 文件
2. 点击"创建模拟实验数据"按钮
3. 点击"测试可视化分析"按钮查看效果

## 技术特点

### 真实数据驱动
- 所有图表都基于 `window.experimentGroups` 中的真实实验数据
- 自动计算重力加速度、周期等物理量
- 支持多组实验数据的对比分析

### 专业图表设计
- 包含背景网格线，便于读数
- 清晰的坐标轴刻度和标签
- 完整的图例说明
- 理论曲线与实际数据的对比

### 响应式布局
- 图表尺寸自适应
- 支持不同屏幕分辨率
- 现代化的UI设计

## 数据格式要求

实验数据应包含以下字段：
```javascript
{
  initialAngle: 5,        // 初始摆角（度）
  length: 30,             // 摆长（厘米）
  periods: [              // 周期数据数组
    { index: 1, duration: 1.0, total: 1.0 },
    { index: 2, duration: 1.02, total: 2.02 }
  ],
  startTime: Date.now(),  // 实验开始时间
  gravity: 9.78           // 计算得到的重力加速度
}
```

## 图表说明

### T vs L 图表
- X轴：摆长L (cm)
- Y轴：周期T (s)
- 红色散点：实验数据
- 绿色实线：理论曲线 T = 2π√(L/g)

### T vs √L 图表
- X轴：√L (cm^0.5)
- Y轴：周期T (s)
- 红色散点：实验数据
- 绿色实线：线性拟合 T = (2π/√g)·√L

### g vs L 图表
- X轴：摆长L (cm)
- Y轴：重力加速度g (m/s²)
- 红色散点：实验数据
- 绿色实线：标准重力加速度参考线 (g = 9.79 m/s²)

### T vs θ 图表
- X轴：摆角θ (°)
- Y轴：周期T (s)
- 红色散点：实验数据
- 绿色实线：平均周期参考线

## 注意事项

1. 确保实验数据完整，包含必要的物理量
2. 图表会自动处理数据范围，确保显示效果
3. 如果没有实验数据，图表会显示相应的提示信息
4. 所有计算都基于国际单位制（SI）
