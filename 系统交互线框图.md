## 图2: 核心数据流详细交互图

```
┌─────────────────────────────────────────────────────────────────────────┐
│                          数据采集与处理流程                              │
└─────────────────────────────────────────────────────────────────────────┘

【摄像头角度识别流程】
摄像头(USB) 
  └─> cv2.VideoCapture.read()
       └─> BGR图像帧(720x1280) ─────────────┐
                                             │
           ┌─────────────────────────────────┘
           ▼
    Detector_HSV.getHsvMask()
           │
           ├─> cv2.cvtColor() ──> HSV图像
           │
           ├─> cv2.inRange() ──> mask二值图
           │        │
           │        └─> hsv_lower=[40,70,70]
           │            hsv_upper=[80,255,255]
           │
           └─> cv2.findContours() ──> 轮廓
                     │
                     └─> cv2.moments() ──> ball_center(cx,cy)
                               │
                               ▼
                      Analyzer.getAngleAndLine()
                               │
                               ├─> dx = ball_x - pivot_x
                               ├─> dy = ball_y - pivot_y
                               │
                               └─> camera_angle = atan2(dx,dy)*180/π
                                         │
                                         ▼
                              PendulumState.update(camera_angle=15.3)
                                         │
                                         ├──> WebSocketServer.broadcast()
                                         │         │
                                         │         └──> 前端pendulum.cameraAngle
                                         │                    │
                                         │                    └──> Canvas.draw()
                                         │
                                         └──> WebCore.get_pendulum_state()
                                                   │
                                                   └──> HTTP响应JSON


【串口摆长识别流程】
单片机(CH340串口)
  └─> Serial_Daemon.run()
       └─> serial.read() ──> "L45.234567\r\n"
                  │
                  └─> Exporter.recordSerialRaw()
                           │
                           └─> serial_raw_history.append("L45.234567")
                                     │
                                     ▼
                          PendulumAPP._processSerialData()
                                     │
                                     ├─> 解析: latest_data.startswith('L')
                                     │
                                     ├─> length_value = float(latest_data[1:])
                                     │              = 45.234567
                                     │
                                     ├─> 数据验证: if length_value <= 100
                                     │
                                     └─> PendulumState.update(physical_length=45.23)
                                               │
                                               ├──> WebCore.get_pendulum_length()
                                               │         │
                                               │         └──> HTTP响应: {"length":45.23}
                                               │                    │
                                               │                    └──> 前端fetchPendulumLength()
                                               │                              │
                                               │                              └──> params.physicalLength
                                               │
                                               └──> WebSocket广播
                                                         │
                                                         └──> 前端同步更新


【用户控制命令流程】
前端按钮点击
  └─> pendulum.js: window.sendKey('d0')
            │
            └─> fetch('http://127.0.0.1:5000/pendulum_key', {
                  method: 'POST',
                  body: JSON.stringify({key: 'd0'})
                })
                     │
                     ▼
              WebCore.pendulum_key()
                     │
                     └─> web_interface.key_queue.put('d0')
                               │
                               ▼
                    PendulumAPP._checkWebKey()
                               │
                               └─> _keyEventWeb(key='d0')
                                         │
                                         └─> Serial_Daemon.send("d0")
                                                   │
                                                   └─> serial.write(b"d0\n")
                                                             │
                                                             └─> 单片机电磁铁关闭
```

## 图3: 实时同步机制详解

```
┌─────────────────────────────────────────────────────────────────────────┐
│                      WebSocket实时推送机制 (20Hz)                        │
└─────────────────────────────────────────────────────────────────────────┘

后端线程1: 主循环 (PendulumAPP.run)
  │
  ├─> while True:
  │     ├─> ret, frame = cap.read()  ──────┐
  │     ├─> _drawn(frame)                   │ 图像采集
  │     │     └─> 更新PendulumState         │ 16ms周期
  │     │                                    │
  │     └─> update_frame(frame) ────────────┘
  │           └─> WebSocketServer.process_camera_frame()
  │                 └─> 更新angle_history/position_history

后端线程2: WebSocket广播循环
  │
  ├─> async def broadcast_loop():
  │     └─> while True:
  │           ├─> await send_pendulum_state()  ───┐
  │           │     └─> JSON: {                   │
  │           │           "type": "pendulum_state"│ 50ms周期
  │           │           "data": {               │ (20Hz)
  │           │             "camera_angle": 15.3  │
  │           │             "physical_length": 45 │
  │           │             "timestamp": 169623.. │
  │           │           }                        │
  │           │         }                          │
  │           │                                    │
  │           └─> await asyncio.sleep(0.05) ──────┘

前端: WebSocket接收处理
  │
  ├─> websocket.onmessage = (event) => {
  │     ├─> data = JSON.parse(event.data)
  │     │
  │     ├─> if (data.type === 'pendulum_state'):
  │     │     └─> _triggerCallbacks('onPendulumState', data.data)
  │     │           └─> Pendulum.syncPendulumAnimation(data.data)
  │     │                 │
  │     │                 ├─> this.cameraAngle = data.camera_angle
  │     │                 ├─> this.params.angle = data.camera_angle
  │     │                 └─> this.draw() ──> Canvas实时更新
  │     │
  │     └─> if (data.type === 'angle_history'):
  │           └─> ChartModule.angleHistory = data.history
  │                 └─> updateAngleChart() ──> Chart.js图表刷新

┌─────────────────────────────────────────────────────────────────────────┐
│                      HTTP轮询机制 (按需触发)                              │
└─────────────────────────────────────────────────────────────────────────┘

前端场景1: 收放摆线时持续轮询
  │
  ├─> 按钮mousedown: btnUpM (收摆线)
  │     │
  │     ├─> window.sendKey('w') ──> 串口发送运动指令
  │     │
  │     └─> startLengthPolling()
  │           └─> setInterval(() => {
  │                 fetchPendulumLength()  ──┐
  │               }, 100)                    │ 100ms轮询
  │                                          │
  ├─> fetchPendulumLength() <────────────────┘
  │     │
  │     └─> fetch('http://127.0.0.1:5000/get_pendulum_length')
  │           └─> 响应: {"length": 45.23, "source": "serial"}
  │                 └─> params.physicalLength = 45.23
  │                       └─> draw() ──> 动画摆长实时更新
  │
  └─> 按钮mouseup: btnUpM
        └─> window.sendKey('a') ──> 停止运动
              └─> stopLengthPolling() ──> clearInterval()

前端场景2: 手动获取数据
  │
  └─> 点击"获取摆长数据"按钮
        └─> fetchPendulumLength() ──> 单次HTTP请求
```
