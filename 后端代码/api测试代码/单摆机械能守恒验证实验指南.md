# 单摆机械能守恒验证实验指南

本实验通过分析单摆运动的角度-时间关系，计算角加速度，绘制角度-角加速度相图，验证单摆运动过程中的机械能守恒定律。

## 实验原理

### 1. 理论基础

对于单摆运动，在小角度近似下：

**运动方程：**
```
θ'' + (g/L)sin(θ) = 0
```

其中：
- θ：角度（弧度）
- θ'：角速度（rad/s）
- θ''：角加速度（rad/s²）
- g：重力加速度（9.8 m/s²）
- L：摆长（m）

**机械能守恒：**
```
E = KE + PE = (1/2)mL²θ'² + mgL(1-cosθ) = 常数
```

### 2. 相图分析法

相图是角速度-角度关系的图形表示，对于守恒系统：

- 相轨迹应该是闭合曲线
- 能量不同对应不同的闭合轨道
- 理想情况下应该呈现椭圆形状

### 3. 数值计算方法

**角速度计算：**
使用中心差分法计算角速度：
```
ω(t) = [θ(t+Δt) - θ(t-Δt)] / (2Δt)
```

**角加速度计算：**
使用二次中心差分法：
```
α(t) = [θ(t+Δt) - 2θ(t) + θ(t-Δt)] / (Δt)²
```

### 1. 数据预处理

```python
import numpy as np
import pandas as pd
from scipy import signal

def preprocess_data(raw_data):
    """
    数据预处理
    """
    # 转换为DataFrame
    df = pd.DataFrame(raw_data)

    # 角度转弧度
    df['angle_rad'] = np.radians(df['angle'])

    # 统一时间戳（从0开始）
    df['relative_time'] = df['time'] - df['time'].iloc[0]

    # 按时间排序
    df = df.sort_values('relative_time').reset_index(drop=True)

    # 去除异常值
    df = df[np.abs(df['angle_rad']) < np.pi/2]  # 去除超过90度的数据

    return df
```

### 2. 计算导数

```python
def calculate_derivatives(df):
    """
    计算角速度和角加速度
    """
    dt = np.mean(np.diff(df['relative_time']))

    # 计算角速度（中心差分）
    omega = np.gradient(df['angle_rad'], dt)

    # 计算角加速度（中心差分）
    alpha = np.gradient(omega, dt)

    df['omega'] = omega
    df['alpha'] = alpha

    return df
```

### 4. 能量分析

```python
def analyze_energy(df, mass=0.1, g=9.8):
    """
    分析机械能守恒
    mass: 摆球质量（kg）
    g: 重力加速度（m/s²）
    """
    L = df['length'].iloc[0]  # 摆长

    # 计算动能
    df['kinetic_energy'] = 0.5 * mass * L**2 * df['omega']**2

    # 计算势能（以最低点为参考）
    df['potential_energy'] = mass * g * L * (1 - np.cos(df['angle_rad']))

    # 计算总机械能
    df['total_energy'] = df['kinetic_energy'] + df['potential_energy']

    # 计算能量变化率
    df['energy_change'] = df['total_energy'] - df['total_energy'].iloc[0]

    return df

def plot_energy_analysis(df):
    """
    绘制能量分析图
    """
    plt.figure(figsize=(12, 8))

    # 能量随时间变化
    plt.subplot(2, 2, 1)
    plt.plot(df['relative_time'], df['kinetic_energy'], 'r-', label='动能', alpha=0.7)
    plt.plot(df['relative_time'], df['potential_energy'], 'b-', label='势能', alpha=0.7)
    plt.plot(df['relative_time'], df['total_energy'], 'k-', label='总能量', alpha=0.7)
    plt.xlabel('时间 (s)')
    plt.ylabel('能量 (J)')
    plt.title('能量随时间变化')
    plt.legend()
    plt.grid(True, alpha=0.3)

    # 能量变化率
    plt.subplot(2, 2, 2)
    plt.plot(df['relative_time'], df['energy_change'], 'g-', alpha=0.7)
    plt.axhline(y=0, color='k', linestyle='--', alpha=0.5)
    plt.xlabel('时间 (s)')
    plt.ylabel('能量变化 (J)')
    plt.title('能量守恒性检验')
    plt.grid(True, alpha=0.3)

    # 相图（能量等高线）
    plt.subplot(2, 2, 3)
    plt.scatter(df['angle_rad'], df['omega'], c=df['total_energy'],
               cmap='viridis', alpha=0.6, s=1)
    plt.colorbar(label='总能量 (J)')
    plt.xlabel('角度 θ (rad)')
    plt.ylabel('角速度 ω (rad/s)')
    plt.title('能量等高线相图')
    plt.grid(True, alpha=0.3)

    # 能量统计
    plt.subplot(2, 2, 4)
    energy_std = df['total_energy'].std()
    energy_mean = df['total_energy'].mean()
    energy_cv = energy_std / energy_mean * 100

    plt.text(0.1, 0.8, f'平均能量: {energy_mean:.6f} J', transform=plt.gca().transAxes)
    plt.text(0.1, 0.7, f'能量标准差: {energy_std:.6f} J', transform=plt.gca().transAxes)
    plt.text(0.1, 0.6, f'能量变异系数: {energy_cv:.4f}%', transform=plt.gca().transAxes)
    plt.text(0.1, 0.5, f'最大能量变化: {df["energy_change"].abs().max():.6f} J',
             transform=plt.gca().transAxes)
    plt.text(0.1, 0.4, f'数据点数: {len(df)}', transform=plt.gca().transAxes)

    plt.title('能量守恒统计')
    plt.axis('off')

    plt.tight_layout()
    plt.savefig('energy_analysis.png', dpi=300, bbox_inches='tight')
    plt.show()
```

## 实验结果分析

### 理想结果特征

1. **相图特征**：
   - θ-ω相图：闭合椭圆轨道
   - θ-α相图：具有对称性的闭合曲线
   - 能量等高线：清晰的能量分层

2. **能量守恒特征**：
   - 总能量曲线接近水平直线
   - 能量变化率接近零
   - 变异系数小于1%

### 误差分析

1. **系统误差**：
   - 空气阻力的影响
   - 摆线质量的影响
   - 轴承摩擦的影响

2. **测量误差**：
   - 摄像头分辨率限制
   - 角度测量精度
   - 时间测量精度

3. **数值误差**：
   - 差分计算的截断误差
   - 采样率不足带来的混叠
   - 数据噪声的影响

## 实验注意事项

1. **数据采集**：
   - 确保采样率足够高（建议≥100Hz）
   - 采集完整周期数据（建议≥5个周期）
   - 避免外部干扰

2. **参数设置**：
   - 初始角度不宜过大（建议≤30度）
   - 摆长测量要准确
   - 环境要稳定

3. **数据处理**：
   - 适当滤波去噪
   - 检查数据连续性
   - 验证计算结果合理性
