# AI演示页面使用说明

## 设计风格

本套演示页面采用与前端系统一致的**深色科技风格**：

- **配色方案**：深蓝黑色调（#0f172a、#1e293b、#3b82f6）
- **布局方式**：Flex弹性布局，紧凑高效
- **视觉效果**：科技感、专业性、严谨性
- **字体规范**：Microsoft YaHei、Segoe UI
- **无多余装饰**：无表情包、无对比卡片、无营销元素

## 自定义修改

### 修改配色
在`<style>`标签中搜索颜色值：
```css
#3b82f6 → 主色调（科技蓝）
#0f172a → 深色背景
#1e293b → 面板背景
#334155 → 边框颜色
```

### 修改数据
在`<script>`标签中修改数值范围：
```javascript
// 例如修改识别准确率
const confidence = (95 + Math.random() * 4.5).toFixed(1);
// 改为
const confidence = (96 + Math.random() * 3).toFixed(1);
```

### 修改动画速度
调整`setTimeout`和`sleep`参数：
```javascript
await sleep(1500);  // 1.5秒
// 改为
await sleep(1000);  // 1秒
```

## 故障排除

### 动画不流畅
- 关闭其他浏览器标签
- 确保使用推荐浏览器
- 检查硬件加速是否开启

### 布局错乱
- 刷新页面
- 检查浏览器窗口大小
- 确保使用标准分辨率

### 按钮无响应
- 检查JavaScript是否启用
- 打开开发者工具查看控制台错误
- 刷新页面重试
